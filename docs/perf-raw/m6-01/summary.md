## How these were produced

Device: Xiaomi Pad 7 (2410CRP4CG), Android 16, HyperOS OS3.0.303.0.WOZIDXM, 3200x2136 @ 120 Hz,
landscape locked, animations off, USB powered. App: `:app` `benchmark` build type (R8,
non-debuggable, debug-signed) from `main` at 82b63ba, installed with
`adb install -r -t app-benchmark.apk`. Test APK: `:benchmark` `benchmark` build type.

Each run is one instrumentation invocation, e.g.

```sh
adb shell am instrument -w \
  -e class app.terbaca.benchmark.SharpenLatencyBenchmark \
  -e androidx.benchmark.suppressErrors 'EMULATOR,DEBUGGABLE,LOW-BATTERY' \\
  app.terbaca.benchmark/androidx.test.runner.AndroidJUnitRunner
adb pull /sdcard/Android/media/app.terbaca.benchmark/app.terbaca.benchmark-benchmarkData.json <name>.json
```

The competitor rows use `app.terbaca.benchmark.CompetitorBenchmarks#scrollFlings` and
`#pinchZoom` with `-e competitor.package app.terbaca -e competitor.component
app.terbaca/.MainActivity -e competitor.mediaId <MediaStore _id of bench-paper_two_column.pdf>`;
their `instrument.txt` is committed beside this file. Perfetto traces and the raw
`benchmarkData.json` files are not committed (about 4 MB per run); the CSVs here carry every
measured sample, and the run is reproducible with the commands above.
